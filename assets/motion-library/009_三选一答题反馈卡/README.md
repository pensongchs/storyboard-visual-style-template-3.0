## 视频调用规则

- 原网页依赖单选按钮点击、`checked` 状态和 `:has()` 结果判断。
- 正式用于视频时，将“展示题目 → 逐项出现选项 → 自动选中 → 显示正确或错误反馈”改为按视频时间轴触发，不等待观众点击。
- 题目、选项、进度和结果文字都必须根据当期中文文案替换，并重新处理中文字体、字号、行距、选项高度、内边距和长文本换行。
- 正确与错误反馈必须与文案真实判断一致；没有明确答案时不得自行虚构正确项。
