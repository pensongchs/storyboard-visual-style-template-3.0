## 视频调用规则

- 推荐用于“但是、真正的问题、而结果是、最终结论、风险出现”等明确转折，也可用于一张普通信息卡切换为风险、重点或结论状态。
- 不推荐用于普通正文、没有状态反转的装饰、多个卡片同时扩散，以及实景主体已经非常明亮复杂的镜头。
- 原组件通过悬停让右上圆形放大到 `800%` 并覆盖卡片。正式用于 Remotion 时改为由转折词或结论字幕节点触发的一次性扩散，完成后稳定停留；不得循环收缩和扩张。
- `HEADING / More Info` 是示例文字。正式视频必须替换为当期中文短标题和必要的一行补充；没有查看或进入下一层信息的操作语义时删除底部按钮和箭头。
- 原橙色只作为演示。普通重点默认改为暖金或低饱和棕金，风险与限制可使用当前完整圆角警示卡的红色；不得直接引入与当期画面无关的高饱和色。
- 正式适配时使用本地字体，不依赖 `font-Poppin`；箭头需要时改用项目已有的内联 SVG 或 CSS 线条，不额外依赖 Font Awesome。
- 圆形扩散应保持边缘干净并覆盖完整卡片，文字在扩散过程中同步切换对比度；必须检查负层级、溢出裁切和中文标题不会被圆形遮挡。
- 本效果定为 L3 高存在感动效，接入工作量中。一次镜头只允许一张卡完成扩散，不与强发光、3D 翻转、弹跳或复杂转场叠加。
