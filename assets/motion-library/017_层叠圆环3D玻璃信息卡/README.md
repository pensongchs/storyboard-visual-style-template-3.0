## 视频调用规则

- 推荐用于单个核心概念、一个关键卖点、一项材料或功能解释、一个阶段结论的主信息卡；适合用右上圆环表达聚焦、层级、扩散或逐层证明。
- 不推荐用于长段正文、多张同类卡片同时出现、需要严肃数据对比的画面、实景主体已经复杂的镜头，以及没有层级或聚焦语义的装饰。
- 原代码依赖悬停触发 30° 立体倾斜、圆环抬升和社交按钮前移。正式用于 Remotion 时改成按字幕时间轴驱动，并将整卡旋转压到约 2°—4°；圆环按当前台词逐层展开后稳定，不保留大幅倾斜或持续漂浮。
- `UIVERSE (3D UI)`、正文、`View more` 和社交平台图标均为示例内容。正式视频必须替换为当期中文短标题与一条辅助说明；无操作或社交语义时删除查看按钮和全部社交按钮，不能把网页功能原样搬进房产视频。
- 右上 Uiverse 标志必须替换为与当期内容相关的简洁图标、数字或短标签，或直接删除。不得在正式视频中保留无关品牌标志。
- 原绿色渐变、厚重阴影和大面积高亮不符合当前分镜基础风格。正式接入时改成炭黑、深暖灰、珍珠白与少量暖金，玻璃层降低透明反差，圆环只保留细微明暗和景深层次。
- 中文标题应控制在 2—10 个字，辅助说明最多两行；必须重新计算标题区、正文区和圆环遮挡范围，不能出现截图中标题被圆环遮住或强制断行的问题。
- 本效果定为 L3 高存在感动效，接入工作量高。平均每 20—30 秒最多使用一次，并优先作为单镜主视觉；不与另一个 3D 卡片、强发光或大幅转场叠加。
