## 视频调用规则

- 推荐用于三项费用、三个区域、三类住宅、三个指标或三个结论按口播逐项讲解，尤其适合每一项都由“短名称 + 核心数字”构成的内容。
- 不推荐用于没有数字的普通清单、超过三项的密集列表、单项名称或说明过长，以及三项必须同时保持完全清晰才能比较的画面。
- Twitter、Facebook、Instagram、平台图标和示例数字均需删除。正式视频根据当期内容更换为语义准确的本地图标或简洁线性图形，并使用有来源的真实数字与中文标签。
- 原组件依赖悬停确定当前项。正式用于 Remotion 时改成按字幕时间轴依次聚焦：当前项轻微放大和提亮，上一项降低亮度后保留，下一项不得提前成为重点。
- 原 `scale(1.1)` 过大，正式适配时控制在约 `1.02—1.04`；非当前项原 `blur(5px)` 会破坏对比阅读，应改为降低亮度、饱和度和透明度，确需模糊时不超过约 `1—2px`。
- 三张卡默认统一为当前模板的深色玻璃或珍珠白材质，只用暖金强调当前项。只有三项本身具有明确的正向、警示、风险差异时才使用不同颜色，不保留社交平台品牌色。
- 正式使用本地字体，并按最长中文名称重新计算卡片宽度、图标区、数字区和对齐基线。右侧数字的单位、正负号和小数位必须统一。
- 本效果定为 L2 结构性动效，接入工作量低。当前项聚焦是唯一主要运动，不与滑块、粒子、强发光或大幅卡片位移叠加。
