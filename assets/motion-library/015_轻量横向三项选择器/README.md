## 视频调用规则

- 推荐用于恰好三项的中性比较、政策口径、条件切换、判断维度、阶段推进或当前项确认。它比 004 深色玻璃滑块更轻、更安静，适合信息密度较高但不需要强烈科技感的画面。
- 不推荐用于超过三项的长清单、单项文字较长、需要纵向阅读的内容，以及没有选择或状态变化语义的装饰。
- 原代码通过 radio 的 `checked` 状态触发选中卡片、缩放和粒子。正式用于 Remotion 时改成按字幕时间轴计算当前项，背景、字重、阴影和轻微缩放按帧同步变化，不保留点击或悬停依赖。
- `First / Second / Third` 只是示例文字。正式视频必须换成当期中文内容，并根据实际字数重新计算整体宽度、三项宽度和内边距；三项应保持同一基线和协调间距。
- 原动画在中段放大到 `1.05`。接入当前分镜模板时应控制在不超过 `1.04`，避免明显弹跳；选择反馈完成后稳定回到 `1`。
- 上下蓝色粒子只在“确认、选中、最终答案”等明确反馈语义下保留，并改成当前辅助色；普通比较或阶段推进应删除粒子，只保留卡片和文字状态变化。
- 浅色外观正式接入时可转成珍珠白信息条叠在实景上，或改为深色玻璃底板与暖白文字；必须服从当期整体材质，不能形成独立的纯白界面风格。
- 本效果定为 L2 结构性动效，接入工作量低。选中状态变化是唯一主要运动，不再叠加滑块位移、大幅发光或其他弹跳效果。
