## 自动匹配速查

强度用于控制画面存在感：L1 为轻量信息变化，L2 为结构性状态变化，L3 为高存在感强调。接入工作量只表示改成中文 Remotion 时间轴效果的预计复杂度，不代表已经完成运行或渲染验证。

|---|---|---|---|
| 001 | 数字成为第一信息主体 | L2 | 低 |
| 002 | 处理中、生成、完成等状态推进 | L2 | 低 |
| 003 | 身份、入口、选中、激活 | L2 | 低 |
| 004 | 三项比较、三步判断、当前项切换 | L2 | 低 |
| 005 | 当前观点、关键词或短说明强调 | L3 | 中 |
| 006 | 关键词、分类或短结论局部强调 | L1 | 中 |
| 007 | 确认、重点词或状态激活 | L3 | 中 |
| 008 | 四项分类、流程或阶段推进 | L2 | 中 |
| 009 | 提问、选择、答案或答案揭示 | L3 | 高 |
| 010 | 操作、价格、比例或关键数值强调 | L3 | 中 |
| 011 | 概念、材料、特点和结论说明 | L1 | 低 |
| 012 | 多场景、多对象或多步骤依次聚焦 | L2 | 中 |
| 013 | 真实数据、指标对比和趋势变化 | L2 | 中 |
