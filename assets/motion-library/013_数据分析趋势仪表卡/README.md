## 视频调用规则

- 推荐用于有明确数据来源的价格、成交量、库存、比例、涨跌幅、周期变化或多项指标对比；不用于没有数据依据的普通观点镜头，也不得保留原示例数字冒充真实数据。
- 正式用于视频时，标题、指标名、数字、涨跌幅、周期和按钮文字必须按当期中文文案替换；数字、单位、正负号和小数位应统一格式，并重新检查手机端字号和间距。
- 原组件的主要动态是卡片悬停放大、外框光晕增强和按钮悬停渐变。接入 Remotion 时改为按字幕时间轴驱动：卡片轻入场，指标在对应台词出现，柱状图按讲述顺序增长，当前指标或当前柱轻度高亮，结论后回到稳定状态。
- `Live` 只有在文案确实表达实时、正在更新或当前状态时保留；普通历史数据应改成准确的周期或状态标签。`View Details` 没有操作语义时删除，不能为了还原网页而保留无意义按钮。
- 柱状图必须使用真实数据或明确的示意关系。使用示意数据时必须避免显示会被误认为真实统计值的精确数字，并在画面语义上明确它只是趋势表达。
- 正式画面应改为当前分镜模板的炭黑、暖灰、暖白和少量暖金体系；紫色、粉色和绿色只在确有语义时作为局部辅助色，不直接照搬整套霓虹渐变。
- 本效果建议定为 L2 结构性动效。若同时加入强烈数字跳动、外框高亮或大幅柱形增长，只保留其中一种主要强调，避免升级成多项叠加的 L3 效果。
