## 视频调用规则

- 推荐用于楼层/总高、已还/总期、当前值/目标值、面积/预算、两个阶段数字，或条件满足后揭示第二个数字的镜头。两组数字之间必须存在清楚且可说明的关系。
- 不推荐用于两个互不相关的数字、没有解锁或揭示语义的普通装饰、长单位和长标签，以及把竖卡直接铺满横版画面。
- `03 / 40` 和 `Touch to unlock` 是示例内容。正式视频必须替换为当期真实数字、短单位和中文关系标签；如果表达时间应使用明确冒号，如果表达比例或进度应补充斜线、单位或“当前/总计”，不能让观众猜测关系。
- 原组件通过悬停触发横纵各 6° 的倾斜和两块模糊色团移动。正式用于 Remotion 时改成由字幕时间轴触发的小幅聚焦，倾斜控制在约 1°—2°，色团只做短距离明暗变化，随后稳定。
- 只有文案确实表达“解锁、满足条件、揭示答案、开放权限”时才保留锁形图标和解锁提示；普通双数字对比应改成准确的关系标签，删除操作暗示。
- 两个数字可按口播顺序先后出现，当前讲到的数字更亮或略大，未讲到的数字不得提前成为重点。所有精确数字必须有明确来源，不使用示例数字。
- 原蓝橙双色光团正式接入时改为深暖灰与暖金，或根据正反、风险与安全语义使用克制的双状态色；不保留无语义的彩色光斑。
- 本效果定为 L2 结构性动效，接入工作量中。竖卡优先作为画面侧边信息卡或与实景并置，不与另一个强数字卡、持续发光或大幅旋转叠加。
