## 视频调用规则

- 推荐用于总价、面积、比例、年限、楼层、套数、成交量、浏览量等一个数字就是当前第一信息主体的镜头，旁边或下方只配一个短单位和一句短结论。
- 不推荐用于没有可靠来源的精确数字、多项数据同时比较、长段正文、实景主体已经复杂的画面，以及把光点当作整镜持续装饰。
- `750k / Views` 是示例内容。正式视频必须替换为当期真实数字、单位和中文标签；数字与单位分层排版，保留准确的小数、百分号和正负号，不擅自换算或制造数据。
- 原光点使用 6 秒无限循环。正式用于 Remotion 时必须改成按字幕时间轴驱动：数字出现后光点沿边框完成一次短距离或一圈巡光并停住，不循环，不在口播已经转入下一层信息后继续移动。
- 数字可在对应台词到达时由暗到亮或轻微递增，光束同步降低后稳定。数字递增只用于已有明确起止值或需要揭示最终值的内容，不能为静态数据虚构变化过程。
- 原黑白金属质感可以保留，但应融入当前炭黑、深暖灰、暖白和少量暖金体系；光束、边框和光点降低亮度，避免形成霓虹科技界面。
- 本效果定为 L2 结构性动效，接入工作量低。巡光是唯一主要运动，不与左右摇摆、强发光、弹跳数字或复杂背景转场叠加。
