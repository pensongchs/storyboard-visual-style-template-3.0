# 分镜素材画面风格模板3.0｜视觉规范

## 风格目标

用真实空间、社区和城市环境建立可信度，用MG图形解释关系与判断。画面应当像一段清楚、克制的房产纪录片，而不是网页组件展示或信息卡片合集。

核心结构：

```text
真实场景 → 语义聚焦 → 关系标注 → 单一判断
```

## 视觉层级

1. 第一层：与台词直接相关的真实房屋、社区、通勤或城市图片。
2. 第二层：一句主标题或当前判断，负责告诉观众这一镜看什么。
3. 第三层：聚焦窗、分割线、轨道、节点、标签等MG解释元素。
4. 第四层：必要的辅助说明；不与主标题争夺注意力。

如果一镜需要观众同时阅读三个以上重点，应拆分状态或拆镜。

## 基础规格

- 默认画幅：16:9。
- 示例分辨率：1280×720。
- 默认帧率：30fps。
- 默认编码：H.264。
- 建议安全区：左右至少 58px；主标题顶部不低于 48px；底部结论和字幕避免低于 570px。

## 配色

| 用途 | 色值 | 使用原则 |
| --- | --- | --- |
| 背景煤黑 | `#090C0D` | 暗部、标签底、分屏过渡底色 |
| 象牙白 | `#F6F0E6` | 主标题和关键正文 |
| 暖金 | `#E4B45E` | 判断、轨道、分割线、重点结论 |
| 亮金 | `#FFD47A` | 当前焦点和瞬时强调 |
| 薄荷绿 | `#9EF1C5` | 能改、可执行、正向状态 |
| 珊瑚红 | `#FF7568` | 不能改、风险、负向状态 |

金色负责“判断”，绿红只负责语义状态。不要把所有边框都做成发光色。

## 字体与排版

- 正式项目优先使用有授权的本地中文黑体或无衬线字体。
- 主标题建议 58–66px、900字重，最多两行。
- 卡片标题建议 28–38px；辅助说明建议不低于 24px。
- 强调词可用暖金色，不依靠频繁换字体制造变化。
- 数字与中文按语义成组，不沿用网页示例的英文字距和固定字符宽度。

字体文件不随 Skill 分发，候选字体与安装方式见 `assets/remotion-template/DEPENDENCIES.md`。

## 三种场景引擎

### 场景聚焦窗

适合单一实景中的局部解释、室内与外部关系、结构和采光判断。

- 背景先轻微压暗。
- 聚焦区域从小到大展开，并恢复亮度与饱和度。
- 描边沿聚焦区域绘制，不穿过主标题。
- 标签通过短引线连接真实位置。
- 结尾只给一个判断条。

避免同时出现多个聚焦窗、边框长期高频闪烁或标签没有真实指向。

### 证据轨道

适合三项优先级、步骤、证据链和决策顺序。

- 横向轨道先绘制，再按口播顺序出现节点与图片。
- 当前项放大、提亮、增加暖金描边。
- 已讲项降低亮度保留；未讲项保持隐藏或弱化。
- 最终判断在底部以笔刷形或简洁结论条出现。

避免四项以上挤在一屏、三张卡片同等明亮或轨道只装饰不表达顺序。

### 语义切分

适合能与不能、内部与外部、短期与长期、利弊或前后对比。

- 第一画面可先铺满全屏，第二画面从中线揭开。
- 中线使用克制暖金光，不做高频闪烁。
- 左右标签按台词顺序出现，当前一侧略微提亮。
- 标题位于中上方，跨分屏时必须有足够暗部或阴影保证可读。

避免两侧都堆满长文、左右素材色温完全冲突或开场留下未填充黑区。

## 动画节奏

- 入场使用 12–24 帧的缓动，优先 `Easing.bezier(0.16, 1, 0.3, 1)`。
- 背景只做 1.03–1.09 的慢推镜或轻微漂移。
- 每次口播新增信息，至少对应一次明确的画面状态变化。
- 标签与结论先建立承载关系，再出现文字；不要所有元素同一帧弹出。
- 所有动画由 `useCurrentFrame()` 与 `interpolate()` 驱动。

## 减少审美疲劳

- 不把整条视频都做成同一种圆角卡片。
- 同一期优先轮换场景聚焦窗、证据轨道、语义切分和纯实景四种状态。
- 一镜只使用一个主引擎；动效库素材作为局部增强，不作为整镜主题堆叠。
- 变化来自构图、焦点和叙事关系，不来自随意增加颜色与装饰。

## 素材与事实

- 优先使用用户提供或已确认授权的真实图片和视频。
- 示例图只用于结构预览，正式成片必须按选题替换。
- 精确数字、趋势线、户型和政策内容必须有可靠来源。
- 多图需要主次：一张主图负责结论，辅助图只提供证据。

## 验收

渲染前检查关键帧；渲染后从最终 MP4 抽取至少四个阶段：开场、展开、强调、结论。逐项检查文字完整、图片比例、边缘安全、遮挡、焦点变化和最终判断是否清楚。
