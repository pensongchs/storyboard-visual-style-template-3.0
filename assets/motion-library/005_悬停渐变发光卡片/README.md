- 原网页依赖 `hover` 触发缩放、圆角和外发光。
- 明确用于视频时，将卡片轻微缩小、描边显现和外发光增强改为按视频时间轴自动触发，不等待鼠标操作。

- 文字内容不得紧贴渐变边框，卡片较窄时优先精简、换行或扩大卡片，不得把中文缩得过小。
