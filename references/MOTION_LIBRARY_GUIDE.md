# 动效素材库使用指南

## 入口

每次调用本 Skill 都主动读 `assets/motion-library/动效登记表.md` 的分类速查，按文案语义筛选；只有决定采用某项后，才读对应文件夹的 `README.md`、HTML、CSS、JSX和截图。

## 选择标准

一项动效至少满足以下三点才适合加入分镜：

1. 能解释当前台词的关系、顺序、选择、数据或状态变化。
2. 在手机端仍能清楚阅读，不依赖鼠标才能理解。
3. 与真实场景、暖金主色和克制纪录片质感能够融合。

不能仅因为效果醒目就调用，也不要为了使用动效库而改变文案含义。

## 转换为 Remotion

1. 提取原效果的核心状态，例如默认、聚焦、选中、展开和结论。
2. 删除对 `:hover`、`:focus`、`:checked`、拖动或点击的实时依赖。
3. 用 `useCurrentFrame()`、`interpolate()` 和口播时间点驱动状态切换。
4. 把循环动效改成一次性动作，完成后稳定停住；除非循环本身承载明确含义。
5. 替换原英文、示例数字、平台图标、远程占位图片和无关按钮。
6. 按中文重新设计字号、字距、换行和承载区域。

## 与默认母模板组合

- 选择器、聚焦列表：适合嵌入实景上的判断路径或并列状态，表达当前项切换。
- 数字卡、趋势卡：适合短暂覆盖在真实场景上，必须标明数据来源。
- 发光按钮、标题卡：只用于短结论或状态确认，不充当普通正文。
- 手风琴画廊：适合连续展示多个房源或社区证据，正式使用时替换全部远程示例图。

每镜最多采用一项动效库主效果，不与另一套强动效同时争夺焦点。这是单镜强度限制，不是全片只能使用一种效果。

## 授权边界

库内每项授权状态目前均为待确认。公开仓库、可下载源码和作者署名都不等于获得商用或再分发许可。无法核实许可时，只研究状态结构并重新独立实现，不直接复制原代码或截图进入正式成片。

## 可直接运行的语义组件

原始素材库包含网页交互代码，不是已经接好的 Remotion 组件。无需将 23 项全部接入；按台词选择候选，再改成时间轴状态。下列组件由本仓库独立实现，不复制授权待确认的第三方源码：

| 台词关系 | 库内候选 | Remotion 入口 | 动态重点 |
|---|---|---|---|
| 三项比较、逐项判断 | 004 / 014 / 015 | `FocusSelector` | 当前项滑动聚焦，未讲项隐藏 |
| 首付、税费、装修、备用金 | 019 / 023 | `CostLayers` | 费用层逐项揭示，当前层突出 |
| 两个相关数字、条件变化 | 018 / 022 | `NumberRelation` | 数字按各自台词揭示，关系线后出现 |
| 转折、风险、结论改变 | 009 / 020 | `RiskReveal` | 转折时原位揭示风险和状态色 |
| 判断顺序、因果路径 | 008 / 015 | `FlowNode` + `DrawLine` | 节点随口播推进，连线逐段绘制 |
| 场景证据、空间对比 | 012 | 图片卡与焦点切换 | 证据依次出现，当前图片突出 |

入口：`assets/remotion-template/src/SemanticMotion.tsx`。可运行示例为 `SemanticMotionShowcase.tsx` 和 Composition `StoryboardTemplate-SemanticMotion`；示例内时间只演示动作，正式制作全部替换为实际字幕帧。与信息卡、胶囊、图片卡组合即可，不强制使用这四种结构。`CostLayers` 采用当前费用大卡与已讲费用侧标签，保证最小尺寸和间距；`NumberRelation` 用于两个相关数字，多数字对照应增加共享锚点或另建适合的结构；`RiskReveal` 的状态色和后半句文字需要不同触发点时分别驱动，不能提前显示未讲结论。

最后一个状态与当前 Composition 同时结束时，基础卡片和 `TimedStage` 保持正常亮度至末帧，不提前淡出。

基础 `InformationCard`、`PearlInfoCard`、`AnimatedPill`、`ChoiceCard` 均支持 `motion="rise|slide|reveal|focus|none"`。动作与语义结构分别选；不同编号最后都变成同一文本框淡入，不能算完成匹配。

```tsx
<FocusSelector
  labels={['通勤', '采光', '噪声']}
  starts={[30, 78, 120]}
  end={160}
/>
```

`starts` 是各项台词开始帧，`end` 是该关系结束帧，均使用当前场景内的时间。每种结构先保证停稳后的信息层级成立，再检查入场前、切换中与退场帧；不要用同时显示所有选项的静态卡片替代顺序揭示。
