## 视频调用规则

- 推荐用于四个区域、四类住宅、四项成本、四个周期或四种状态之间的真实数据切换，尤其适合“当前项名称 + 核心数值 + 涨跌幅 + 趋势”的连续解释。
- 不推荐用于没有可靠数据来源的观点、超过四项的密集比较、只需要一个数字的镜头，以及每项名称过长无法在横向滑块中清楚显示的内容。
- `CryptoApp`、币种、价格、持有量、涨幅和趋势线都是示例。正式视频必须替换为当期中文栏目、真实对象、准确数字、单位、周期和数据来源；不得把示例币价或走势用于正式内容。
- 原组件依赖 radio 点击和 `:has()` 切换滑块、数字与图表。正式用于 Remotion 时改成按字幕时间轴计算当前项，滑块、数字、涨跌幅和趋势线同步更新，不保留点击或悬停依赖。
- 原 `display: none / block` 会造成内容跳变，正式适配时改为透明度、裁切或短距离接力；滑块原有过冲缓动改为克制缓动，图表 `scale(1.05)` 调整到当前模板允许范围内。
- 趋势线必须由真实数据点生成，不能用原示例 SVG 路径冒充事实。没有完整时间序列时可以只展示有来源的起止变化或两点关系，不虚构折线波动。
- 涨幅为正、负或持平时分别使用克制的正向色、警示色和中性色，不固定全部使用荧光绿。默认配色改为炭黑、深暖灰、暖白和暖金，图表填充降低饱和度与透明度。
- `Open App` 没有实际操作语义时删除；顶部栏目名可以替换为当期主题，也可以省略。四项中文标签按最长文字重新计算宽度和字号，不直接沿用固定百分比位移。
- 本效果定为 L2 结构性动效，接入工作量中。同一镜头按口播最多完成一轮四项切换，当前项趋势绘制一次后稳定，不连续自动轮播。
